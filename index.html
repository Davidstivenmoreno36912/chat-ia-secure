Sobre el proyecto

Chat con IA es una aplicación web que permite al usuario interactuar con un modelo de inteligencia artificial mediante la API de Google Gemini.

El proyecto demuestra la integración entre una interfaz web desarrollada con tecnologías frontend y un servicio externo de inteligencia artificial.

Objetivo

Construir una aplicación web capaz de recibir preguntas, consumir una API externa, procesar respuestas en formato JSON y mostrar los resultados al usuario en tiempo real.
